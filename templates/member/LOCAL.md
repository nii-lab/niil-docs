# 개인 공간 설정

- template_version: 0.1
- owner_id: {{owner}}
- workspace_kind: member
- participant_type: student / alumni / collaborator 중 선택
- affiliation: 현재 소속 또는 독립 참여
- repository_owner: nii-lab
- personal_repository: 관리자에게 배정받은 nii-lab/독립-개인-저장소
- repository_access: 교수 Admin / 담당자 Write / 나머지 조직 멤버 Read
- access_scope: 실제 승인된 프로젝트와 repository만 기록
- upstream: 프로젝트 참여 후 승인된 repository URL을 기록
- default_visibility: personal
- shared_record_root: records/
- nas_root: 연결 후 내 계정이 접근 가능한 경로를 기록
- delegated_scope: 기록 정리·로컬 검증·공유 초안 작성. 외부 전송 범위는 사용자가 정함.

이 공간이 공용으로 읽히는 repository라면 비공개 메모는 별도 로컬/비공개 저장소에 둔다.

개인 visibility는 Wiki 공유 범위다. 조직 repo에 push한 파일은 멤버가 읽으며 혼자 볼 자료는 .local/private/에 둔다.
