# NiiL 연구 공간

먼저 AGENTS.md와 LOCAL.md를 읽고 current.md에서 재개한다.
records/에는 공통 JSON 기록, notes/에는 작업 메모, results/에는 공유할 결과 요약을 둔다.
대용량 원자료·모델은 NAS에 두고 assets.json에 출처·버전·checksum을 기록한다.

첫 요청: “AGENTS.md를 읽고 내 공간 설정에서 비어 있는 항목을 알려줘.
개인 메모를 유지하면서 예제 기록 하나를 만들어 첫 공유를 연습하게 해줘.”

JSON 기록은 record.example.json을 참고한다. 예제의 빈 source revision과
evidence는 실제 근거가 생겼을 때 채운다. 샘플 수치를 실제 결과로 제출하지 않는다.
