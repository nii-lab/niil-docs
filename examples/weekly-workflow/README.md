# 가상 주간 업무 입력

SIMULATION ONLY. 실제 연구 데이터/계정/미팅/승인이 아니다.

가상 월요일 합의: 기존 센서 로그의 설정 A/B 지연과 누락을 비교해 다음 미팅에서
설정 유지 여부와 추가로 필요한 근거를 논의한다. 확인 기준은 평균 latency ≤10ms 및 누락 없음이다.
실제 센서 성능/안전은 판단하지 않는다. 새 데이터 수집은 이번 연습 범위에 없다.

measurements.csv는 원본 로그다. summarize.py는 평균만 집계하는 기존 도구이며
전체 판정에 필요한 모든 정보를 제공한다고 보장하지 않는다.

기존 자동 메모(학생 미확인): “B의 평균이 더 낮으므로 B 채택을 제안합니다.”
실제 측정과 이 해석을 구분해서 검토한다.
