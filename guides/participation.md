# 실제 참여를 요청하는 공개 접점

개인 로컬 실습은 초대 없이 진행한다. 공용 프로젝트에 참여하려면 실제 GitHub 계정과
연구실 운영자의 별도 검토가 필요하다. 공개 매뉴얼을 읽었다고 멤버 권한이 생기지는 않는다.

## 담당자를 알고 있다면

가입 안내를 준 연구실 구성원/프로젝트 책임자에게 실제 GitHub login과 참여 목적을 전달한다.
프로젝트 ID를 모르면 “미정”이라고 적고 안내를 요청한다. 개인 연구 저장소 전체나 비밀값은 보내지 않는다.

## 처음이라 담당자를 모른다면

공개 매뉴얼 저장소의 [참여 요청 양식](https://github.com/nii-lab/niil-docs/issues/new?template=participation.yml)을
사용한다. [접수 목록](https://github.com/nii-lab/niil-docs/issues)에서 본인이 만든 요청의 답변을 확인한다.
GitHub 계정이 없으면 [GitHub 가입](https://github.com/signup)을 본인이 완료한 후 양식을 연다.
가입 전에도 LOCAL-ONLY 개인 공간과 첫 기록은 만들 수 있다.

이 Issue는 **공개**다. 이미 공개된 GitHub login, 재학생/졸업생/협력 희망 여부,
공개해도 되는 관심 주제와 프로젝트 미정 여부만 적는다. 학번·전화·개인 이메일·비공개 연구·
개인 repo/정책/토큰은 적지 않는다. 비공개 확인이 필요하면 운영자가 별도 경로를 안내한다.
Agent는 초안을 보여 주고 사용자가 이번 공개 게시를 승인한 뒤에만 전송한다.
이 안내를 읽은 것만으로 게시나 초대를 승인받은 것으로 해석하지 않는다.

접수는 가입 승인이 아니다. repository 운영자가 검토하며 자동 초대·권한 부여·즉시 회신을 보장하지 않는다.
초대 수락 → private hub Read → 실제 numeric ID/project 등록 → 본인 위임 선택을 각각 확인한다.
요청이 대기 중이면 needs_access로 보존하고 개인 작업을 이어간다.

## 운영자에게 보낼 짧은 초안

- GitHub login: 실제 계정 또는 아직 미가입
- 참여 형태: 재학생 / 졸업생 / 협력 희망
- 공개 가능한 관심 주제: 한 문장
- 참여 프로젝트: 실제 이름 또는 미정
- 필요한 안내: 초대 / 프로젝트 안내 / 계정 연결 중 해당 항목

사람이 실제로 확인한 계정/범위만 등록한다. 가상 LOCAL-ONLY ID나 예시 계정은 등록하지 않는다.
