# NiiL에 처음 참여한다면

사용 중인 Codex 또는 Claude Code에 아래 안내를 붙여넣으세요.
연구실 배경지식이나 GitHub 초대 없이 **내 컴퓨터의 개인 공간과 첫 기록**부터 시작합니다.

```text
나는 NiiL에 처음 참여합니다.
https://raw.githubusercontent.com/nii-lab/niil-docs/main/START-HERE.md 를 읽고 안내해 주세요.
내 환경에서 할 수 있는 일부터, 개인 공간과 첫 기록을 함께 만들어 주세요.
자동 실행·승인·알림 범위는 내가 선택하게 하고, 지금 필요한 질문만 해주세요.
공동 참여에 필요한 계정·초대·권한·agent 연결은 해당 단계에서 확인해 주세요.
```

첫날에는 **내 공간 · 다음 할 일이 적힌 기록 · 내가 정한 공유와 승인 범위**를 준비합니다.
완료하지 않은 연결은 다음 단계로 남깁니다. 자세한 안내는 [START-HERE](START-HERE.md)에 있습니다.
