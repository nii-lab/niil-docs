공통 계약은 개인·공동 프로젝트에 함께 사용합니다. common/과 member/ 또는 project/의
파일을 합쳐 새 공간을 구성하고 LOCAL.md를 실제 역할과 승인 범위에 맞게 설정합니다.
이 저장소는 공개 문서 원본입니다. 포털은 고정된 버전을 연결해 읽기 쉽게 제공합니다.
